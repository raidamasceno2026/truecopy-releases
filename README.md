# TrueCopy — versões

Aqui ficam só as versões prontas do **TrueCopy** para macOS (backup verificado e organização de cartões de memória).
O app instalado procura atualizações aqui sozinho. O código-fonte não fica neste repositório.

Para instalar: baixe o `.zip` da versão mais nova em **Releases**, abra e arraste o TrueCopy para **Aplicativos**.
